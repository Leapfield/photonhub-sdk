# Security policy

Do not report a vulnerability, leaked credential, private design, or other
sensitive material in a public issue.

Use a [private GitHub security advisory](https://github.com/Simupod/simupod/security/advisories/new)
for security reports. Include the affected SDK version, a minimal reproduction,
impact, and any suggested mitigation. Remove API keys and customer data from all
attachments.

Use the public issue tracker only for non-sensitive bugs and documentation
questions. The SDK is pre-1.0; security fixes target the newest released version
unless a separate support agreement says otherwise.
